# 🐍 Day 56 - Flask Jinja Templates

## 100 Days of Python - Angela Yu

This is my Day 56 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

A personal profile website built with Flask
and Jinja templates.

The project demonstrates how Python data can
be passed to HTML templates and dynamically
rendered using Jinja.

## ✨ Features

- Flask web application
- Jinja templates
- Dynamic content
- Python dictionaries
- Python lists
- Jinja variables
- Jinja for loops
- Static CSS
- Multiple Flask routes

## 📚 Topics Covered

- Flask
- Jinja
- `render_template()`
- Template variables
- Jinja expressions
- Jinja `for` loops
- Dictionaries
- Lists
- Static files
- HTML
- CSS

## 🛠 Technologies

- Python
- Flask

- HTML
- CSS
