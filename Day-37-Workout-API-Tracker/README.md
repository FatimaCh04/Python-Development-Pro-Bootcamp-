## ✨ Features

- Accept exercise information from the user
- Send data to an external API
- Receive exercise information
- Display exercise duration
- Display estimated calories
- Handle API and network errors
- Keep API credentials outside the source code

## 🛠 Technologies

- Python 3
- Requests
- REST API
- JSON
- python-dotenv

## 📦 Installation

Install the required libraries:

```bash
pip install requests python-dotenv
```

## ⚙️ Configuration

Create a `.env` file:

```env
API_KEY=your_api_key_here
APP_ID=your_app_id_here
```

Never upload `.env` to GitHub.

## ▶️ Run

```bash
python main.py
```
