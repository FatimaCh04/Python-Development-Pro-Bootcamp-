# Elite Washwo — Frontend UI

A polished React + Vite frontend concept for the Elite Washwo stock, sales, salesman ledger, returns, expenses and reconciliation system.

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Important
This package is a frontend/design foundation only. Data is currently demo data so the UI can be reviewed before connecting Supabase.

The final implementation should replace demo data with transaction-derived Supabase queries, Row Level Security, storage policies, audit trails, PDF generation and the complete business rules from the project specification.
