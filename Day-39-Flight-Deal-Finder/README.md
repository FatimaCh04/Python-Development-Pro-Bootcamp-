## 📚 Course

100 Days of Python - Day 39 Practice

## 🎯 Topics Covered

- REST APIs
- API Authentication
- HTTP GET Requests
- Query Parameters
- JSON Data
- Environment Variables

## ✨ Features

- Search flights between two airports
- Use IATA airport codes
- Fetch flight information from an external API
- Display airline and flight number
- Display departure and arrival times
- Display flight status
- Handle API and network errors

## 🛠 Technologies

- Python 3
- Requests
- REST API
- JSON
- python-dotenv

## 📦 Installation

Install the required packages:

```bash
pip install requests python-dotenv
```

## ⚙️ Setup

Create a `.env` file:

```env
API_KEY=your_api_key_here
```

Never upload `.env` to GitHub.

## ▶️ Run

```bash
python main.py
```

## ✈️ Example

```text
Enter departure airport IATA code: LHE
Enter arrival airport IATA code: DXB
```
