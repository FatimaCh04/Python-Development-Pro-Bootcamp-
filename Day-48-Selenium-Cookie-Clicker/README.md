# 🍪 Day 48 - Selenium Cookie Clicker Bot

## 100 Days of Python - Angela Yu

This is my Day 48 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

An automated Cookie Clicker bot built using
Selenium WebDriver.

The bot opens Cookie Clicker, automatically
clicks the cookie, checks available products,
and purchases affordable upgrades.

## ✨ How It Works

1. Opens Chrome using Selenium.
2. Navigates to Cookie Clicker.
3. Finds the main cookie element.
4. Automatically clicks the cookie.
5. Checks available upgrades.
6. Determines whether an upgrade is affordable.
7. Purchases an available upgrade.
8. Continues for a fixed amount of time.
9. Displays the final cookie score.
