# 📊 Day 25 - Student CSV Analyzer

## 📚 Course

100 Days of Python - Day 25 Practice

## 🎯 Topics Covered

- Pandas Library
- Reading CSV Files
- DataFrames
- Filtering Data
- Basic Statistics

## ✨ Features

- Read student data from a CSV file
- Display all records
- Calculate average, highest, and lowest marks
- Find the top-performing student
- Search for a student by name

## 🛠 Technologies

- Python 3
- Pandas

