# ☕ Day 66 - RESTful API

## 100 Days of Python

A RESTful API built with Flask and SQLAlchemy.

## Features

- Get random cafe
- Get all cafes
- Search cafes by location
- Add new cafes
- Update coffee prices
- Delete closed cafes
- JSON responses
- API key authentication
- SQLite database

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- REST API
- Postman
