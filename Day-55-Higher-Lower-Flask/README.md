# 🎯 Day 55 - Higher or Lower Game with Flask

## 100 Days of Python - Angela Yu

This is my Day 55 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

A simple Higher or Lower number guessing game
built using Python and Flask.

The application generates a random number
between 0 and 9.

The user selects a number and Flask determines
whether the guess is:

- Too high
- Too low
- Correct


```text

```

## 🎮 How to Play

1. Start the Flask server.
2. Open the application in your browser.
3. Choose a number from 0 to 9.
4. The application tells you whether the
   number is higher, lower, or correct.
5. Continue guessing until you win.
