# 📚 Day 63 - Virtual Bookshelf

## 100 Days of Python - Angela Yu

A virtual bookshelf built with Flask,
SQLite and SQLAlchemy.

## ✨ Features

- View books
- Add books
- Edit books
- Delete books
- Book ratings
- SQLite database
- SQLAlchemy ORM
- Dynamic sorting
- Responsive UI

## 📚 Concepts Covered

- Flask
- SQLite
- Flask-SQLAlchemy
- SQLAlchemy Models
- CRUD
- HTML Forms
- POST Requests
- Dynamic Routes
- Jinja Templates
- Database Queries
- Sorting

## 🛠 Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Jinja
- Bootstrap
- HTML
- CSS

## ▶️ Run

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

Open:

```text
http://127.0.0.1:5000
```
