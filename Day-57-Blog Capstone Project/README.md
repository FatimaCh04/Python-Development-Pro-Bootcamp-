# 🐍 Day 57 - Blog Capstone Project

## 100 Days of Python - Angela Yu

This is my Day 57 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

A dynamic personal blog website built with
Python, Flask, Jinja and Bootstrap.

## ✨ Features

- Responsive homepage
- Dynamic blog posts
- Individual post pages
- About page
- Contact page
- Dynamic Flask routes
- Jinja templates
- Bootstrap styling
- Responsive design

- Flask

- Dynamic routes

- HTML
- CSS
