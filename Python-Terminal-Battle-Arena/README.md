# 🛡️ Python Terminal Battle Arena

## Project

Python Terminal Battle Arena is a Command-Line RPG game developed in Python.

The player controls a Warrior who must defeat multiple enemies across three waves:

- Wave 1: Two Goblins
- Wave 2: Two Orcs
- Wave 3: Dragon Boss

After each wave, the player enters a shop where gold can be spent to purchase attack upgrades or healing potions.

The game demonstrates the use of Nested Dictionaries, Functions, Loops, Random Module, Input Validation, and Turn-Based Game Logic.
