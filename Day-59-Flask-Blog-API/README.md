# 🐍 Day 59 - Flask Blog API

## 100 Days of Python - Angela Yu

This is my Day 59 project from Angela Yu's
100 Days of Python journey.

## 🎯 Project

A dynamic Flask blog application that retrieves
blog posts from an external JSON API and displays
them using Jinja templates.

## ✨ Features

- Flask web application
- External API integration
- JSON data handling
- Dynamic blog posts
- Individual post pages
- Jinja templates
- Bootstrap responsive UI
- Error handling
- Dynamic routes

## 📚 Concepts Covered

- Flask
- API Requests
- JSON
- `requests`
- `response.json()`
- Jinja
- Dynamic Routes
- `url_for()`
- Template Inheritance
- Bootstrap
- Error Handling

## 🛠 Technologies

## 📦 Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python main.py
```

Open:

```text
http://127.0.0.1:5000
```
