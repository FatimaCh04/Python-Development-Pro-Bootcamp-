# 💕 Day 50 - Tinder Automation with Selenium

## 100 Days of Python - Angela Yu

This is my Day 50 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

A Selenium-based browser automation project
inspired by the Tinder Swiping Bot project.

The project demonstrates how Selenium can:

- Open a website
- Interact with a browser
- Find buttons
- Read button text
- Read HTML attributes
- Handle browser interaction
- Automate repetitive browser tasks

## 📚 Topics Covered

- Selenium WebDriver
- Browser Automation
- `find_elements()`
- `By.TAG_NAME`
- `.text`
- `.get_attribute()`
- Loops
- Exception Handling
- Time Delays
- Interactive Browser Automation

## 🛠 Technologies

- Python
- Selenium
- Google Chrome

## 📦 Installation

Install Selenium:

```bash
pip install selenium
```

## ▶️ Run

```bash
python main.py
```

The program opens the website and allows
the user to complete login or verification
manually.

After that, Selenium demonstrates how to
inspect visible buttons and their attributes.

## 🧠 What I Learned

Through Day 50 I learned how to:

- Automate browsers using Selenium
- Find multiple elements
- Inspect HTML elements
- Read text from elements
- Read element attributes
- Work with loops
- Handle exceptions
- Build browser automation scripts

## ⚠️ Note

Modern websites frequently change their HTML
structure and may restrict automated interactions.

This project is intended for educational purposes
and demonstrates Selenium browser automation
concepts rather than automatically performing
actions on real user accounts.
