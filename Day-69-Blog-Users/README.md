# 📝 Blog Capstone — Day 69

A complete personal blog application built with Python, Flask,
SQLite, SQLAlchemy and Flask-Login.

This project focuses on adding users and authentication to a
database-driven blog application.

---

## 🚀 Features

- User registration
- User login
- User logout
- Password hashing
- Session management
- Protected routes
- Create blog posts
- Edit blog posts
- Delete blog posts
- Post ownership
- Author information
- SQLite database
- SQLAlchemy ORM
- Responsive UI
- Flash messages
- Admin-style access for user ID 1

---

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- HTML5
- CSS3
- Bootstrap
