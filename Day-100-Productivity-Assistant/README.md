# 🚀 Day 100 – Productivity Assistant

A modern **Productivity Assistant web application** built with Python and Flask. The project is designed to help users organize daily tasks, track productivity, monitor progress, and view useful analytics through a clean and responsive dashboard.

This project represents the completion of the **100 Days of Python Development journey**, combining Python programming, Flask web development, database management, frontend development, and data visualization concepts into one practical application.

---

## ✨ Features

* 📋 Create and manage daily tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📊 Productivity analytics dashboard
* 📈 Task completion statistics
* 🎯 Productivity progress tracking
* 🗓️ Daily task organization
* 💾 Persistent SQLite database
* 📱 Responsive and user-friendly interface
* 🎨 Clean modern dashboard design
* 🔄 Dynamic task updates
* ⚡ Flask-powered backend

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project directory

```bash
cd Day-100-Productivity-Assistant
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in your browser

```text
http://127.0.0.1:5000
```

## 📊 Analytics Dashboard

The application includes a dedicated analytics page where users can monitor productivity information such as:

* Total tasks
* Completed tasks
* Pending tasks
* Completion percentage
* Productivity trends
* Daily progress

This provides users with a simple way to understand their productivity patterns.

## 🗄️ Database

The application uses **SQLite** for lightweight and persistent data storage.

The database stores task information and allows the application to maintain data between sessions.
