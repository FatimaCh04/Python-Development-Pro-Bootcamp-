# 🗳️ Day 9 - Student Voting System (Practice)

## Topics Covered

- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input

## Project

This project simulates a simple voting system.

Users can:

- Add votes for candidates
- Store votes using dictionaries
- Display all candidates
- Find the winner automatically

## Learning Outcomes

- Working with dictionaries
- Updating dictionary values
- Creating reusable functions
- Finding maximum values
- Looping through dictionary items

```bash
python main.py
```
