# 🐍 100 Days of Python — Day 72

## Data Visualisation with Matplotlib

A practice project for Day 72 of Angela Yu's **100 Days of Code:
The Complete Python Pro Bootcamp**, focused on visualising data with
Matplotlib.

### What I Practiced

- Pandas CSV loading
- Matplotlib figures
- Bar charts
- Line charts
- Comparison bar charts
- Scatter plots
- Pie charts
- Titles and axis labels
- Legends and grids
- Basic data insights

### Project Structure

```text
Day-72-Data-Visualisation/
├── main.py
├── weekly_learning_data.csv
├── requirements.txt
└── README.md
```

### Install

```bash
py -m pip install -r requirements.txt
```

### Run

```bash
py main.py
```

If `py` is unavailable:

```bash
python -m pip install -r requirements.txt
python main.py
```

The CSV is an original small practice dataset made for this project;
the purpose is to practice the Day 72 visualisation techniques.
