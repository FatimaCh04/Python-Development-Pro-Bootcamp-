# 🐢 Day 19 - Keyboard Control Game

## Course

100 Days of Python - Day 19 Practice

## Topics Covered

- Turtle Graphics
- Event Listeners
- Keyboard Input
- Functions
- Higher-Order Functions

## Features

- Move turtle using arrow keys
- Turn left and right
- Move backward and forward
- Pen Up / Pen Down
- Reset turtle position

## Controls

⬆️ Up Arrow → Move Forward

⬇️ Down Arrow → Move Backward

⬅️ Left Arrow → Turn Left

➡️ Right Arrow → Turn Right

R → Reset Position

U → Pen Up

D → Pen Down

## Technologies

- Python 3
- Turtle Module

## Run

```bash
python main.py
```

## Learning Outcomes

- Handling keyboard events
- Using event listeners
