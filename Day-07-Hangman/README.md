# 🎮 Day 7 - Hangman Game

## Topics Covered

- for loops
- while loops
- if / else
- Lists
- Strings
- Random Module
- Functions

## Project

Hangman is a text-based word guessing game.

The computer randomly selects a word from a predefined list.

The player guesses one letter at a time.

Each incorrect guess decreases the player's remaining lives.

The game ends when:
- The player guesses the complete word.
- The player loses all lives.

## Learning Outcomes

- Practice loops
- Work with lists and strings
- Update game state
- Build a complete console game

## Run

```bash
python main.py
```
