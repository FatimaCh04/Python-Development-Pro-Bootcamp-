# 🐼 Day 73 - Aggregate & Merge Data with Pandas

## 📊 Project: College Major vs Salary

This project is part of Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp**.

On Day 73, I worked with Pandas to analyze real-world college major and salary data.

The project explores the relationship between college majors, starting salaries, and mid-career salaries.
