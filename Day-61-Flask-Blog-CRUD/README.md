# 🐍 Day 61 - Flask Blog CRUD

## 100 Days of Python - Angela Yu

A database-driven Flask blog application
with CRUD functionality.

## ✨ Features

- Create blog posts
- Read blog posts
- Edit blog posts
- Delete blog posts
- SQLite database
- SQLAlchemy ORM
- Dynamic routes
- Jinja templates
- Bootstrap UI
- Responsive design

## 📚 Concepts

- Flask
- SQLite
- SQLAlchemy
- CRUD
- GET
- POST
- Forms
- Dynamic Routes
- Jinja
- Bootstrap
