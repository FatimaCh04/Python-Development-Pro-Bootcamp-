# 📝 Day 65 – Web Design: Build Your Own Blog

## 100 Days of Python – Angela Yu

Today I continued my **100 Days of Python journey** by building a personal blog website using Flask, HTML, CSS, Bootstrap, and Jinja templating.

The main focus of Day 65 was **Web Design** and creating a clean, responsive blog layout.

---

## 🚀 Project Overview

This project is a simple personal blog where users can:

- 🏠 View the homepage
- 📝 View blog posts
- 📖 Read individual posts
- 👩‍💻 Visit an About page
- 📱 Use the website on different screen sizes
- 🎨 Experience a responsive and modern design

---

## ✨ Features

- Responsive blog homepage
- Blog post cards
- Individual blog post pages
- About page
- Navigation bar
- Responsive layout
- Bootstrap styling
- Custom CSS styling
- Dynamic Flask routes
- Jinja template rendering

---

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- HTML5
- CSS3
- Bootstrap 5
- Jinja2
