# Day 8 - Caesar Cipher (Practice)

## Topics Covered

- Functions
- Parameters
- Loops
- String Manipulation
- Encryption
- Decryption

## Project

This is a practice implementation of the Caesar Cipher algorithm.

Features:
- Encode messages
- Decode messages
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and punctuation
- Allows multiple operations until the user exits

## Run

python main.py
