# ☕ Day 62 - Coffee & WiFi

## 100 Days of Python - Angela Yu

A Flask web application for discovering
work-friendly cafes.

## ✨ Features

- View cafes
- Add new cafes
- Delete cafes
- SQLite database
- WiFi availability
- Power socket availability
- Coffee availability
- Coffee pricing
- Responsive Bootstrap UI

## 📚 Concepts Covered

- Flask
- SQLite
- Flask-SQLAlchemy
- Database Models
- Boolean Fields
- HTML Forms
- POST Requests
- CRUD
- Jinja Templates
- Bootstrap

## 🛠 Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Jinja
- Bootstrap
- HTML
- CSS

## ▶️ Run

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

Then open:

```text
http://127.0.0.1:5000
```

I learned how to build a Flask application
