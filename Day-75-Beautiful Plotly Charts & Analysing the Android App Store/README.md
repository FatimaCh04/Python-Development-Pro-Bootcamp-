# 🐍 Day 75 — Beautiful Plotly Charts & Analysing the Android App Store

This project is part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

## 📊 Project Overview

In Day 75, I explored the **Google Play Store dataset** using Python and Pandas. I cleaned and analyzed app data and created interactive visualizations using **Plotly** to understand app categories, ratings, reviews, installations, pricing, and other trends.

## 🚀 What I Learned

* Working with CSV datasets using Pandas
* Cleaning and preparing data
* Handling missing values
* Removing duplicate records
* Converting data into appropriate numeric types
* Grouping and aggregating data
* Analyzing app ratings and reviews
* Comparing free and paid applications
* Creating interactive charts with Plotly
* Using bar charts, histograms, pie charts, and scatter plots

## 📈 Analysis Included

The project analyzes:

* 📱 Most popular app categories
* ⭐ Distribution of app ratings
* 📊 Average rating by category
* 💬 Reviews vs. ratings
* 💰 Free vs. paid apps
* 👨‍👩‍👧 Content rating distribution
* 🔥 Most reviewed apps
* 📥 Most installed apps
* 💵 Paid app prices
* 📈 Total reviews by category

## 📦 Installation

Install the required libraries:

```bash
pip install pandas plotly
```

Or use:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Make sure `apps.csv` is in the same folder as `main.py`.

Then run:

```bash
python main.py
```

The interactive Plotly charts will be generated during execution.
