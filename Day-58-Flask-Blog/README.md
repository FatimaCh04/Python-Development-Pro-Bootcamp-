# 🐍 Day 58 - Flask Blog with Bootstrap

## 100 Days of Python - Angela Yu

This is my Day 58 project from Angela Yu's
100 Days of Code: The Complete Python Pro Bootcamp.

## 🎯 Project

A responsive Flask blog website built using
Python, Flask, Jinja and Bootstrap.

## ✨ Features

- Responsive navigation bar
- Blog homepage
- Dynamic blog posts
- Individual post pages
- About page
- Contact page
- Jinja template inheritance
- Bootstrap responsive layout
- Dynamic URLs
- Mobile-friendly design

## 📚 Topics Covered

- Flask

- Template Inheritance

- `url_for()`
