What is HousePrice AI?

HousePrice AI is a full-stack machine learning web application that predicts Pakistani residential property prices from four inputs: area in square feet, number of bedrooms, number of bathrooms, and neighbourhood.

Every prediction comes from a Random Forest Regressor pipeline trained on real estate data that you upload. There are no hardcoded formulas and no static example values. The model is saved with Joblib and reloaded on every prediction request — training only happens when you explicitly click "Train Model" on the ML Dashboard.

The ML Dashboard lets you upload any compatible CSV dataset, inspect its contents, train a new model, and immediately see the updated R², MAE, and RMSE metrics alongside a freshly generated Actual vs Predicted scatter chart.
