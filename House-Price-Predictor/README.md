# HousePrice AI 🏡

A complete end-to-end **Machine Learning + Flask** web application that predicts Pakistani real estate prices using a trained Random Forest model.

---

## Project Overview

HousePrice AI lets users enter a property's area, number of bedrooms, bathrooms, and neighbourhood to receive an instant AI-powered price estimate in PKR — powered by a **RandomForestRegressor** trained on a realistic synthetic dataset of 1200 Pakistani property records.

---

## Features

| Feature | Detail |
|---|---|
| ML Model | RandomForestRegressor (200 trees) |
| Dataset | 1200 records, 8 Pakistani locations |
| Preprocessing | Median imputation, Standard Scaler, One-Hot Encoding |
| Evaluation | R², MAE, RMSE on 20% hold-out test set |
| Backend | Flask REST API (`POST /predict`) |
| Frontend | Professional single-page responsive UI |
| Testing | 12 pytest test cases |
| Serialization | Full sklearn Pipeline saved via Joblib |

## Dataset

- **File:** `house_data.csv`
- **Records:** 1200
- **Columns:** `area_sqft`, `bedrooms`, `bathrooms`, `location`, `price`
- **Locations:** DHA, Bahria Town, Clifton, Gulberg, Model Town, PECHS, Gulshan, North Nazimabad
- **Prices:** realistic PKR values using location-specific land rates + construction costs

---

## ML Workflow

1. Load CSV → validate columns → drop missing targets
2. Split: **80% train / 20% test** (`random_state=42`)
3. **ColumnTransformer:**
   - Numeric (`area_sqft`, `bedrooms`, `bathrooms`): `SimpleImputer(median)` → `StandardScaler`
   - Categorical (`location`): `SimpleImputer(most_frequent)` → `OneHotEncoder(handle_unknown='ignore')`
4. **RandomForestRegressor** (200 estimators, `random_state=42`)
5. Evaluate on test set → print R², MAE, RMSE → save to `model/metrics.json`
6. Save complete pipeline to `model/house_price_model.pkl` via `joblib.dump`

## API Endpoint

### `POST /predict`

**Request:**
```json
{
  "area_sqft": 2000,
  "bedrooms": 3,
  "bathrooms": 2,
  "location": "DHA"
}
```

**Success Response:**
```json
{
  "success": true,
  "predicted_price": 18500000,
  "currency": "PKR"
}
```

**Error Response:**
```json
{
  "success": false,
  "error": "Area must be greater than zero."
}
```
