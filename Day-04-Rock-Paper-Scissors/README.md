# Day 4 - Rock Paper Scissors

## Topics Covered

- Random Module
- Lists
- Indexing
- Conditional Statements
- Game Logic

## Project

A console-based Rock Paper Scissors game where the player competes against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is determined according to the game rules.

## How to Run

```bash
python main.py
```

## Learning Outcomes

- Using Python's random module
- Working with lists
- Building simple game logic
- Decision making with if-else
