## 📦 Installation

Install Flask:

```bash
pip install Flask
```

Or install all dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python main.py
```

Then open:

```text
http://127.0.0.1:5000
```
