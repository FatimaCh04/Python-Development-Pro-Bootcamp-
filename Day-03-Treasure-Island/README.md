# Day 3 - Treasure Island

## Topics Covered

- if / else
- Nested if statements
- Logical thinking
- User input
- String methods
- Decision making

## Project

Treasure Island is a text-based adventure game.

The player makes choices throughout the game.

Different choices lead to different endings.

Only one path leads to the hidden treasure.

## How to Run

```bash
python main.py
```

## Example

Welcome to Treasure Island.

Your mission is to find the treasure.

wait

yellow

Congratulations! You found the treasure.

## Learning Outcomes

- Understand conditional statements
- Practice nested if statements
- Learn decision-based programming
- Improve logical thinking
