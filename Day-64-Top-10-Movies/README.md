# 🎬 Day 64 - Top 10 Movies Website

## 100 Days of Python - Angela Yu

A Top 10 Movies website built with Flask,
SQLite and SQLAlchemy.

## ✨ Features

- Display movies
- Movie rankings
- Movie ratings
- Movie reviews
- Movie descriptions
- Movie posters
- Add movies
- Edit ratings and reviews
- Delete movies
- SQLite database
- Responsive design

## 📚 Concepts Covered

- Flask
- SQLite
- Flask-SQLAlchemy
- SQLAlchemy Models
- CRUD
- Database Queries
- Sorting
- Dynamic Routes
- Jinja Templates
- HTML Forms
- Bootstrap

## 🛠 Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Jinja
- Bootstrap
- HTML
- CSS

## ▶️ Run
